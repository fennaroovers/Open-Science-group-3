**Instructions for 3D printing the parts:**

**SET-UP AND PREPARATION**
1) Go to Lili's Protolab and look at this Github repository. Look at the .jpg file in the results section for a picture of the gearbox you will make.

2) Access one of the '3D printer control' computers.

3) Log in to the Github repository on this computer to access the files.

4) In the documents folder, there is a link to a YouTube video on the basics of 3D-printing if you would prefer to watch a video beforehand.

5) Opening the hardware files on the computer:
     - Download the .step files from the hardware folder.
     - Open the Prusa Slicer application.
     - Import the .step files into the Prusa Slicer application.
  
6) Opening all the files together will lead to an assembled gear box, see picture. To print the parts, you will need to separate them.

![image 1](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%201.png)



**SEPARATING THE PARTS AND PREPARING THEM FOR PRINTING**
1) Select the part you want to move on the right panel. The part you have selected will be highlighted. 

![image 2](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%202.png)

![image 3](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%203.png)
   
3) Move the selected part to another place. Repeat until all pieces are separated. 

![image 4](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%204.png)

4) Reorient the top
   - Select the piece that is the top of the gearbox - the one with V2 on it.
   - We want to change the orientation to avoid it floating.
   - In the left side bar we can perform operations.
   
![image 5](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%205.png)
        
   - Click 'Place on face'. 

![image 6](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%206.png)
   
   - Select the upper face. 
   
![image 7](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%207.png)  
    
   - For the result see picture.

![image 8](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%208.png)
  
5) Reorient the Gear V2 (see picture)

![image 9](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%209.png)

   - Repeat the steps but select 'Lay down on face' option and select the upper face.
   - For the result see the picture.

![image 10](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2010.png)
  
6) Slicing
   - Switch to the slicing tab by clicking the icon of the sliced box in the lower left corner.

![image 11](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2011.png)
   
   - Click on 'slice now' in the bottom right.

   - For the result see picture.

![image 13](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2013.png)
  
**PREPARING THE PRINTER**
1) Choose the print settings. You should use half the printer nozzle, i.e. if the printer nozzle is 0.4 you should choose 0.2. 

![image 14](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2014.png)

2) Choose the PLA filament. The colour does not matter. 

![image 15](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2015.png)

3) Choose one of the printers with a 0.4 nozzle. 

![image 16](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2016.png)

4) Load the filament you want into the printer you have chosen.

5) Send the printing instructions to the printer by clicking 'Send to connect'.

![image 17](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2017.png)

6) Select the printer where you loaded the filament. 

![image 18A](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2018A.png)

![image 18B](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2018B.png)

7) The printer should receive the file and download it. 

![image 19](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2019.png)

8) The printer will calibrate. Once the calibration is done, the printer will start printing. Keep an eye on the printer during the process to make sure everything is printed correctly. See pictures. [We selected the brim option, so our pieces look slightly different than yours should look like. The little layer around the pieces should not be there for you.]

![image 20](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2020.png)

![image 21](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2021.png)

**FINISHING THE PRINTING**
1) Once the printer is done we need to take the pieces off. Take the plate off the printer, hold it on both sides and slightly bend it to separate the pieces from the plate. Use the blue piece to get them off. 

 ![image 22](https://github.com/fennaroovers/Open-Science-group-3/blob/main/images/Image%2022.png)

2) Now you have your finished 3d printed parts.
