Instructions for 3D printing the parts:


SET-UP AND PREPARATION
1) Go to Lili's Protolab and look at this Github repository. Look at the .jpg file in the results section for a picture of the gearbox you will make.

2) Access one of the '3D printer control' computers.

3) Log in to the Github repository on this computer to access the files.

4) In the documents folder, there is a link to a YouTube video on the basics of 3D-printing if you would prefer to watch a video beforehand.

5) Opening the hardware files on the computer:
     - Download the .step files from the hardware folder.
     - Open the Prusa Slicer application.
     - Import the .step files into the Prusa Slicer application.
